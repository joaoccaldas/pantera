# Pantera

Cannabis strain search and discovery app. Browse strains by name, type, THC/CBD content, effects, and flavors.

## Features

- Strain search with autocomplete
- Detailed strain profiles
- CSV-based strain database
- Responsive design

## Getting Started

Open `index.html` in a browser.
